# Buteyko Platform

**Основатель:** Анна (Founder)
**Статус:** Концепт / Pre-MVP

## 1. Суть проекта
Создание глобальной цифровой платформы-маркетплейса для метода Бутейко. Метод — это медицинская технология (зарегистрированное изобретение), направленная на нормализацию дыхания. 

## 2. Проблема
Правообладатель (Клиника Бутейко в Москве) обучает методистов и выдает им сертификаты (с ежегодным продлением). Однако нет цифрового контроля за их работой. Нет приложения, где методисты могли бы вести клиентов, а клиенты — находить проверенных специалистов.

## 3. Решение (Продукт)
Платформа-маркетплейс, где:
* **Клиент** выбирает проблему (стресс, тревога, психосоматика) и находит методиста по рейтингу.
* **Методист** ведет дневник сессий, общается с клиентом по видеосвязи.
* **Клиника** контролирует качество (интеграция с реестром сертификатов: нет действующего сертификата — нет доступа к платформе).
* **Масштабирование:** AI-синхронный перевод для работы с клиентами по всему миру.

## 4. Бизнес-модель (Монетизация)
* Комиссия с каждой сессии (15–20%).
* B2B-продажа курсов для новых методистов.
* Premium-подписка для методистов (расширенная CRM).
* Роялти правообладателю за использование бренда.

## 5. Технические вызовы
* Как обеспечить GDPR-безопасность (данные о здоровье)?
* Как построить архитектуру для видеозвонков (WebRTC) и AI-перевода?
* Как интегрироваться с реестром сертификатов Клиники (через API или вручную на старте)?
